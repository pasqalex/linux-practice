# passGen.sh

Простой генератор паролей на Bash. Использует `/dev/urandom` для генерации случайных символов.

> **Статус:** учебный проект. Рефакторинг завершён: логика разбита на функции, валидация вынесена отдельно, рекурсия заменена на `while`.

## Что умеет

- генерировать пароли длиной от 5 до 20 символов
- генерировать несколько паролей за один запуск (от 1 до 50)
- использовать или не использовать специальные символы
- работать в интерактивном режиме
- переспрашивать ввод при ошибке, не сбрасывая весь скрипт

## Требования

- Linux / WSL / macOS
- Bash
- утилита `tr` (входит в `coreutils`)

## Запуск

chmod +x passGen.sh
./passGen.sh

## Как работает

Скрипт задаёт несколько вопросов:

1. Начать? (`yes`, `y`, `yup`, `yeah`, `start`, `go`)
2. Длина пароля (5–20 символов)
3. Сколько паролей сгенерировать (1–50)
4. Использовать специальные символы? (`yes` / `no`)

Если ввод неверный - функция переспрашивает, не сбрасывая скрипт.

## Пример вывода

| Hi! Welcome to my simple password generator based on /dev/urandom. |
----------------------------------------------------------------------

Here we go? yes
Enter password length (5 - 20 symbols): 12
How many passwords do u need? 3
Can I use special symbols? yes

Password generator started, please wait...
Passwords generated successfully!
-> aB3$kL9!mN2@
-> xY7#pQ1&rT4%
-> zW8^vU5*sE6!
Done!

## Генерация

Используется `tr` с диапазоном символов:

- без спецсимволов: `A-Za-z0-9`
- со спецсимволами: `A-Za-z0-9!@#$%^&?*_`

Символы берутся из `/dev/urandom` - это криптографически стойкий источник случайности в Linux.

## Структура

Весь код в одном файле. Функции:

- `colorGreen` - зелёный текст
- `colorRed` - красный текст
- `greetings` - приветствие и вопрос «Начать?»
- `askLength` - спросить и проверить длину пароля
- `askCount` - спросить и проверить количество паролей
- `symbols` - спросить про спецсимволы, вернуть 0 или 1
- `generator` - сгенерировать один пароль
- `main` - основная логика, вызывает остальные функции

## Что изменилось с прошлой версии

- `main` разбит на отдельные функции
- рекурсивный вызов `main` заменён на `while true` внутри функций
- проверки ввода вынесены в отдельные функции
- `generator` параметризован: принимает длину и флаг спецсимволов
- убран двойной вызов `symbols`
- исправлена передача аргументов в `generator`
