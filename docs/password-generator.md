# passGen.sh

Простой генератор паролей на Bash. Использует `/dev/urandom` для генерации случайных символов.

> **Статус:** учебный проект. Будет доработан: разбит на функции, добавлены проверки ввода, улучшена читаемость.

## Что умеет

- генерировать пароли длиной от 5 до 20 символов
- генерировать несколько паролей за один запуск (до 50)
- использовать или не использовать специальные символы
- работать в интерактивном режиме

## Требования

- Linux / WSL / macOS
- Bash
- утилита `tr` (входит в `coreutils`)

## Запуск

chmod +x passGen.sh
./passGen.sh

## Как работает

Скрипт задаёт несколько вопросов:

1. Начать? (`yes`, `y`, `yup`, `yeah`, `go`)
2. Длина пароля (5–20 символов)
3. Сколько паролей сгенерировать (1–50)
4. Использовать специальные символы? (`yes` / `no`)

После этого генерирует пароли и выводит их на экран.

## Пример вывода

| Hi! Welcome to my simple password generator based on /dev/urandom. |
----------------------------------------------------------------------

Here we go? yes
Enter password length (5 - 20 symbols): 12
How many passwords do u need? 3
Can I use special symbols? yes

Password generator started, please wait...
Passwords generated successfully!
aB3$kL9!mN2@
xY7#pQ1&rT4%
zW8^vU5*sE6!

## Генерация

Используется `tr` с диапазоном символов:

- без спецсимволов: `A-Za-z0-9`
- со спецсимволами: `A-Za-z0-9!@#$%^&?*_`

Символы берутся из `/dev/urandom` - это криптографически стойкий источник случайности в Linux.

## Структура

Весь код в одном файле. Функции:

- `colorGreen` - зелёный текст
- `colorRed` - красный текст
- `main` - основная логика
