# linux-practice

Учебный репозиторий для практики Linux и Bash-скриптов.

## Что внутри

- базовые команды Linux
- работа с файлами и директориями
- права доступа
- процессы и мониторинг
- Bash-скрипты для автоматизации

## Как использовать

1. Клонировать репозиторий:

git clone https://github.com/pasqalex/linux-practice.git
cd linux-practice

2. Сделать скрипт исполняемым:

chmod +x scripts/hello.sh

3. Запустить:

./scripts/hello.sh

## Что тренирую

- навигация по файловой системе
- работа с правами (chmod, chown)
- поиск файлов (find, grep)
- архивация (tar, gzip)
- планирование задач (cron)
- написание Bash-скриптов
- SSH

## Заметки

Личный учебный репозиторий. Пополняется по мере изучения Linux.
